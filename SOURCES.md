## Remplacer une ressource

Chaque image est un fichier WebP autonome dans `assets/img/<dossier>/`. Pour la remplacer :
conservez le même nom de fichier (ou mettez à jour `assets/js/products.js` pour les produits)
et la résolution indiquée dans l'attribut `width` du HTML.
